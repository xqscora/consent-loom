# Consent Loom

Consent Loom is a CSH Social Impact Ideathon concept for the AI track. It treats AI as a constrained parser inside a consent system: the model proposes a support protocol from the student's own words, and a deterministic verifier plus explicit confirmation controls what can be shared.

The proposal is intentionally not a chatbot, diagnosis tool, emotion classifier, or permanent student profile. Its testable claim is narrower: student-authored support can become faster to act on when provenance, expiry, and revocation are first-class data fields.

Read `SUBMISSION_PACK.md` for the complete Devpost-ready idea, `DEVPOST_OPERATOR_CARD.md` for the external action boundary, `pitch.html` for the supporting visual, and `prototype.html` for the working local state machine. `demo/` contains three review screenshots and a short WebM walkthrough. The narrated demo is available as an unlisted YouTube video at https://youtu.be/1j84uVINZ2w.
